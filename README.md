pairwise against the judge's brief — single word, funny alone, true of the
whole internet, surprising, lands in one beat.

## Run it

```sh
python3 main.py
```

Writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
